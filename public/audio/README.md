# Audio Assets Directory

Store all audio assets for the Interspeech paper project page here.

IMPORTANT RESEARCH INTEGRITY & PRIVACY NOTICE:
- Do NOT upload or commit private, unreleased, or sensitive human subject audio (e.g. from FluencyBank / Voices of Children Who Stutter) unless explicitly authorized for public distribution.
- All audio assets referenced by the website MUST be served locally from this directory (`/public/audio/`).
- Never pass audio files to external online inference or processing APIs.
